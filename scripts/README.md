# Automation & Diagram Scripts

This directory contains standalone Node.js automation scripts used to generate visual assets and test evidence:

- `capture-all.mjs`: Automated Chrome headless script to capture high-DPI screenshots of the SingSlot application views. Outputs images directly to `docs/screenshots/sprint-1/`.
- `render-diagram.mjs` & `render-diagram-exact.mjs`: Scripts to render high-resolution system architecture diagrams to `docs/screenshots/sprint-1/`.
